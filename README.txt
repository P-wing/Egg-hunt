

This a "Level" is intended as an entry for the SMWTrolls.com competition "Make us Laugh Troll Contest". The goal is collect all the legally distinct dino Eggs. There are 9 Eggs, collecting them all make a "You Win" message pop up on the screen (Sorry for Spoilers). 

To start the game, run egg_hunt.exe.

Best played with Audio on btw, though music in the background might be nice as well.
